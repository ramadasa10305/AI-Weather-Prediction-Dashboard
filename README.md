# 🌦 AI Weather Prediction Dashboard

An AI-based Weather Prediction Dashboard developed using **Machine Learning** and **Streamlit**.

## 📌 Features

- 🌧 Rain Tomorrow Prediction
- 📊 Interactive Dashboard
- 📈 Model Comparison
- 📉 Weather Data Analysis
- 🤖 Random Forest Machine Learning Model

## 🛠 Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## 📂 Dataset

**WeatherAUS Dataset**

- Historical weather observations
- 49 Australian locations

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest ✅ (Selected)

## 🎯 Accuracy

**Random Forest Accuracy: 85.11%**
